# openFriedhof

Freie Software für die Friedhofsverwaltung von Kommunen und Kirchengemeinden in Deutschland.

- Quelloffen unter EUPL 1.2
- Offenes Datenformat, keine Anbieterbindung
- Für den deutschen Rechtsrahmen: Satzungen, Nutzungsrechte und Gebühren konfigurierbar

**Status:** Konzeptphase. Wir suchen Pilotpartner unter Friedhofsträgern, besonders in Vorpommern.
